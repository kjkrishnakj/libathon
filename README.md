# 📚 BookHive 🐝 – Buzz into a Smarter Library

Welcome to **BookHive** – a smart, AI-powered digital library platform where borrowing books is as smooth as honey and searching is quicker than flipping a page!

Built for **Libathon 2025**, this project aims to blend **AI**, **modern web tech**, and a pinch of humor to create the ultimate library experience.

---

## 🐝 Features

- 🔍 **Real-Time Book Search** with MongoDB Queries
- 📖 **Issue & Return System** with User Tracking
- 🤖 **AI-Powered Book Recommendations** via OpenAI
- 📸 **Cover Preview from Cloud Storage**
- 🧠 **Leaderboards & User Insights**
- 🗺️ **Book Slug-based Dynamic Routing**
- 🔐 **Login Authentication & Role-based Access**
- ☁️ **Deployed on Vercel for Lightning Speed**

---

## ⚙️ Full Tech Stack

| Layer         | Technology |
|---------------|------------|
| **Frontend**  | Next.js, React.js, Tailwind CSS, Lucide Icons, Shadcn/UI |
| **Backend**   | Node.js, Express.js |
| **Database**  | MongoDB Atlas, Mongoose |
| **AI Engine** | OpenAI API (GPT-4) |
| **Auth**      | JSON Web Tokens (JWT), bcrypt.js |
| **State**     | React Hooks (useState, useEffect), Context API |
| **Deployment**| Vercel |
| **Image Hosting** | MongoDB |
| **Routing**   | Next.js App Router with Dynamic Routes |
| **Form & Validation** | HTML Forms, Native Validations, Optional Zod |
| **Dev Tools** | ESLint, Prettier, GitHub |
